세 단계로 시작하세요.

  1. 호출 단축키를 정하세요. 첫 실행에서 편한 조합을 선택합니다. 기본값은 ⇧⌘V이며 설정에서 바꿀 수 있습니다. 기존 단축키와 겹치면 다른 조합을 선택하세요.
  2. 기록 시작에 동의한 뒤 새로 복사하세요. 텍스트를 선택하고 ⌘C를 누릅니다. 기록 시작 전 내용은 소급 저장하지 않습니다.
  3. 입력할 곳에서 기록을 호출하세요. 대상 앱의 입력칸을 클릭하고 정한 단축키를 누릅니다. 한 번 클릭은 미리보기, 더블클릭·Enter는 선택 항목 사용입니다.

상단 메뉴 막대의 클립보드 아이콘으로도 기록을 엽니다. Dock 아이콘이 필요하면 설정의 ‘Dock에 앱 표시’를 켜세요. 설정 → 일반 → 언어에서 한국어·English·시스템 언어를 선택합니다.

방금 복사한 내용이 보이지 않나요?

  1. ‘기록 중’인지 확인하세요. 일시 중지 중이었다면 다시 시작하고 내용을 새로 복사합니다.
  2. 검색어를 비우고 ‘전체 기록’을 선택하세요. 작은 창이라면 ‘전체 창으로 보기’로 전환해 그룹도 확인합니다.
  3. 왼쪽 아래 ‘작업 모드’는 새 복사를 모을 그룹입니다. 원치 않는 그룹에 쌓이면 ‘그룹 없이 기록’으로 바꾸세요. 기존 항목은 전체 기록에서 확인합니다.
  4. 제외 앱·민감 항목 설정과 앱이 안내하는 macOS 클립보드 접근 상태를 확인하세요. 기록 접근과 직접 붙여넣기 권한은 별개입니다.
  5. 텍스트나 이미지 자체를 복사했는지 확인하세요. Finder의 파일 복사는 이 버전에서 기록하지 않습니다. 용량 한도 안내가 나오면 불필요한 기록·고정 항목을 검토하세요.

긴 글은 본문 앞 8KB와 제목·그룹을 검색합니다. 이미지 속 글자를 인식하는 OCR 검색은 제공하지 않으므로 이미지 제목과 그룹으로 정리하세요.

더블클릭·Enter로 붙여넣기

설정의 ‘더블클릭·Enter로 원래 앱에 바로 붙여넣기’를 켜고 ‘설치·권한 점검’에서 현재 설치된 앱의 손쉬운 사용 권한을 확인합니다. 대상 입력칸 클릭 → 호출 단축키 → 항목 더블클릭 또는 선택 후 Enter 순으로 사용하세요.

창은 닫히는데 입력되지 않아요.

대상 앱의 입력칸에 커서를 두고 다시 호출하세요. 호출 후 다른 앱으로 이동하거나 새로 복사하면 진행 중인 전달이 취소됩니다. 직접 붙여넣기 옵션과 ‘권한 상태 다시 확인’을 점검하고, 대상이 편집 가능한 입력칸인지 확인합니다. 선택한 기록을 복사한 뒤 대상 앱에서 ⌘V로 넣을 수도 있습니다.

복사만 하고 돌아가고 싶어요.

직접 붙여넣기 옵션을 끄세요. 우클릭 메뉴의 ‘복사’는 항상 복사만 합니다. 내용을 받을 앱에서 ⌘V를 누르세요.

손쉬운 사용 권한이 없어도 검색·편집·복사는 사용할 수 있습니다. macOS의 암호·Touch ID 인증은 직접 완료하며 지원 메일로 보내지 마세요.

이미지를 붙이기 전에 편집하기

  1. 이미지를 복사하고 이미지를 받을 문서나 앱의 입력 영역을 클릭합니다.
  2. 기록을 호출하고 이미지 항목의 ‘이미지 편집…’을 선택합니다. 작은 창에서는 우클릭 메뉴로 엽니다.
  3. 자르기·펜·화살표·도형·텍스트·가리기 도구로 표시합니다. 실행 취소·다시 실행·원본으로 돌아가기를 사용할 수 있습니다.
  4. ‘편집해서 붙여넣기’로 전달하거나 ‘편집 결과 복사’ 후 대상에서 ⌘V를 누릅니다. 원본 기록은 유지하며 편집 결과는 PNG로 전달합니다.
이미지 대신 글자가 복사돼요.

미리보기에서 텍스트 인식 영역이 선택됐을 수 있습니다. 미리보기 → 도구 → 직사각형 선택으로 이미지 영역을 선택해 복사하세요. Finder의 이미지 파일 복사와 이미지 픽셀 복사는 다릅니다.

색상·굵기가 비활성화돼요.

펜·화살표·도형·텍스트처럼 색상과 굵기를 쓰는 도구를 선택하세요. 자르기 경계는 고정 굵기이며 가리기는 선택 영역을 검은색으로 완전히 채웁니다.

자주 쓰는 색을 저장하고 싶어요.

색상 선택창이나 6자리 #RRGGBB 코드를 사용해 적용한 뒤 별표 ‘색상 저장’을 누릅니다. 저장한 견본을 눌러 재사용하며 최대 24색을 저장합니다. 마지막 선택 색도 기억합니다. 바꾼 색·굵기는 새 표시에 적용하고 기존 표시는 바꾸지 않습니다.

편집한 이미지가 대상에 안 보여요.

대상이 PNG 붙여넣기를 지원해야 합니다. 일반 텍스트 입력칸에는 이미지를 표시하지 못합니다. 확인할 때는 텍스트 편집기의 서식 있는 문서를 사용하세요. 편집창은 제목 표시줄로 이동하며 다른 앱을 선택하면 그 앱 뒤로 갈 수 있습니다.

작고 간단한 호출창 맞추기

설정 → 호출 창에서 ‘작고 간단한 기록 창으로 호출’을 켭니다. ‘호출창 미리보기 표시’를 켜면 너비·높이·불투명도 변경을 바로 볼 수 있습니다. 슬라이더는 작은 창 모드가 켜져 있을 때 조절됩니다.

미리보기 제목 표시줄로 이동하고 빨간 닫기 버튼으로 숨깁니다. 닫은 뒤에는 표시 옵션으로 다시 켭니다. ‘미리보기 다시 배치’는 찾기 편한 위치로 정렬합니다. 실제 기록창의 전체 보기에서 상세 미리보기와 그룹을 사용하세요.

고정·그룹·여러 기록 삭제

반복해서 쓸 기록을 고정하고 작업 그룹으로 모으세요. Shift 클릭은 범위 선택, ⌘클릭은 개별 선택입니다. 선택 항목 삭제 후 화면의 실행 취소 또는 기록 목록에 포커스가 있을 때 ⌘Z로 최근 삭제 묶음을 되돌릴 수 있습니다.

최근 삭제 묶음의 실행 취소는 10초 동안 제공됩니다. 모든 기록 삭제와 저장소 완전 초기화는 이 방식으로 복원하지 못합니다. 초기화는 일반적인 기록·권한 문제의 첫 해결 방법으로 사용하지 마세요.

내 Mac에서 기록 관리하기

텍스트·이미지와 직접 작성한 이름을 로컬에서 암호화하며 기록을 앱 운영 서버나 AI 서비스에 자동 전송하지 않습니다. 시각·용량 같은 운영 메타데이터는 암호화하지 않습니다. 기본 보존은 30일·최대 5,000개·총 512MB입니다. 고정 기록은 자동 만료되지 않지만 용량 한도에는 포함됩니다.

민감한 내용을 복사하기 전 기록을 일시 중지할 수 있습니다. 제외 앱과 민감 표식은 수집을 줄이지만 모든 비밀을 식별하지는 못합니다. 보존·제외 항목을 바꾸면 ‘보존·제외 설정 저장’으로 적용하세요.

이번 버전에는 자동 번역·OCR·클라우드 동기화가 없습니다. Mac 도우미는 8개 내장 주제와 즐겨찾기를 제공합니다. 기기 내 주제 분류를 사용할 수 없는 환경에서도 기본 안내는 사용할 수 있습니다.
